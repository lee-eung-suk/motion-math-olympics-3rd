# 🏃 수학 체육올림픽 (초등 3학년 2학기)

**초등학교 3학년 2학기 수학 × 체육 융합 · 모션인식 기반 웹 교육 게임**

태블릿을 책상 위에 놓고 앉은 채로, 손을 움직이거나 태블릿을 터치하거나 PC에서 마우스로 조작하며 즐기는 6종목 미니게임 모음입니다. 별도 설치 없이 웹 브라우저에서 바로 실행되며, 학생 개인이 60초 동안 각 종목의 기록에 도전합니다.

`motion-math-olympics`(2학년판) · `motion-math-olympics-1st`(1학년판)과 같은 엔진·화면 구조를 쓰는 **시리즈 3번째 작품**입니다.

---

## 📖 소개

3학년 2학기 수학 6개 단원(곱셈, 나눗셈, 원, 분수, 들이와 무게, 그림그래프)을 **3학년 체육과의 「속도 도전」과 「경쟁의 기초(태그형 게임·술래잡기)」** 영역과 묶어 6종목으로 재구성했습니다.

앉은 자세에서 손동작만으로 조작할 수 있게 설계했고, 학생이 "달린다·쫓는다·따라간다"는 신체 감각을 화면 안에서 그대로 경험하도록 만들었습니다.

## ✨ 주요 특징

- **3가지 조작 방식**: 모션인식(카메라로 손 인식) / 터치 모드(태블릿) / 마우스 모드(PC)
- **자동 난이도 조절**: 3연속 정답이면 한 단계 올라가고, 2연속 실패면 내려가는 자동 조절 (⭐ 개수로 표시)
- **하이라이트 자동 저장**: 플레이 중 가장 잘한 순간의 사진과 3초 영상을 자동으로 만들어 기기에 저장 가능 (서버에는 저장되지 않음)
- **완전 반응형**: PC, 태블릿, 모바일 어떤 화면 크기·가로/세로 방향에서도 사용 가능
- **오프라인 친화적 설계**: 손 인식 AI 모델을 자체 서버에 내장해, 학교 네트워크 환경에서도 안정적으로 동작

## 🎮 6개 종목

| 종목 | 이름 | 수학 주제 | 체육 연계 | 조작 방식 |
|---|---|---|---|---|
| 1 | ⚡ 스피드 곱셈 대시 | 곱셈 | 달리기 속도 | 1인칭 트랙에서 다가오는 숫자 골대 중 **정답 골대를 손으로 통과** |
| 2 | 🏃 도망가는 몫! 태그 나눗셈 | 나눗셈 | 술래잡기 | 손을 피해 **도망치는 정답을 쫓아가 붙잡기**(태그) |
| 3 | 🎯 굴렁쇠 원 코스 | 원 | 원형 코스 | 여러 크기의 굴렁쇠 중 **조건에 맞는 것에 손을 대고 가만히** 있어 원 완성 |
| 4 | 🍕 분수 조각 모으기 | 분수 | 수집 추격 | 그림·띠·숫자·말·대분수로 **얼굴이 제각각인 조각 중 조건에 맞는 것만 수집** |
| 5 | ⚖️ 저울 균형 릴레이 | 들이와 무게 | 릴레이 속도 | 반대로 흐르는 **두 줄의 컨베이어**에서 같은 양을 낚아채 저울 맞추기 |
| 6 | 📊 그래프 징검다리 | 그림그래프 | 경로 추적 | 그림그래프를 읽고 **정답 줄의 발판을 순서대로 콕콕** 짚어 건너기 |

각 종목은 60초 동안 진행되며, 기록에 따라 동/은/금 메달이 주어집니다. 초등 저학년도 바로 조작할 수 있도록 판정 반경을 넉넉히 잡고, 조작 방식은 되도록 "가까이 대기 · 순서대로 짚기"처럼 단순하게 만들었습니다.

## 📚 단원별 학습 단계 (자동 난이도 3단계)

| 종목 | ⭐ 1단계 | ⭐⭐ 2단계 | ⭐⭐⭐ 3단계 |
|---|---|---|---|
| 1 곱셈 | (두 자리)×(한 자리) 올림 없음 | 일의 자리에서 올림 한 번 | 올림이 여러 번 (모두 두 자리×한 자리) |
| 2 나눗셈 | 구구단 범위, 몫 한 자리 | 몫이 두 자리인 나눗셈 | 나머지가 있는 나눗셈의 몫 |
| 3 원 | 굴렁쇠 1구간 · 2칸 간격 · 반지름 제시 | 2구간 · 1~2칸 간격 · 지름 섞임 | 3구간 · 1칸 간격 · 지름 위주 |
| 4 분수 | 그림·숫자로 같은 분수 찾기 | 진분수 / 가분수 가려내기 (+띠·말) | 분모가 같은 분수의 크기 비교 (+대분수) |
| 5 들이와 무게 | 1 kg = 1000 g, 1 L = 1000 mL | 복합 단위(2kg 100g 등) ↔ 단일 단위 | 복합 단위끼리의 덧셈·뺄셈 |
| 6 그림그래프 | 가장 많은 것 찾기 · 발판 4개 | 가장 적은 것 / 특정 수 찾기 | 두 번째로 많은 것 / 특정 수 · 발판 5개 |

오답 선택지는 아이들이 실제로 하는 실수(올림 빠뜨리기, 단위 혼동 등)를 흉내 내도록 만들어, 찍어서 맞히기 어렵게 했습니다. 종목 1은 (두 자리)×(두 자리) 암산이 저학년에게 너무 어려워 전 단계에서 제외했습니다.

## 💻 로컬에서 실행하기

바탕화면 경로에서는 로컬 서버가 권한 문제로 실행되지 않으므로, `/tmp`에 사본을 두고 서빙합니다.

```bash
rm -rf /tmp/mmo3 && mkdir -p /tmp/mmo3 && cp -R "/Users/mac/Desktop/클로드/motion-math-olympics-3rd/." /tmp/mmo3/ && cd /tmp/mmo3 && python3 -m http.server 8793
```

브라우저에서 `http://localhost:8793` 접속. (카메라 권한이 필요한 모션인식 모드는 `localhost` 또는 HTTPS 환경에서만 정상 동작합니다.)

## 🎨 설계 노트

### 마리오파티처럼 보이게 만든 것들
화면 위 모든 것을 `js/cute.js` 한 곳에서 같은 규칙으로 그립니다.

- **통통한 스티커 도형**: 아래로 떨어지는 그림자 + 굵은 남색 외곽선 + 위쪽 유광 하이라이트
- **두꺼운 외곽선 글자**: 카메라 영상 위에 얹혀도 숫자가 또렷하게 읽힙니다
- **하얀 장갑 커서**: 손 위치를 마리오파티식 장갑으로 표시하고, 잡는 순간 노랗게 달아오릅니다
- **표정**: 숫자 하나에도 눈과 발그레한 볼을 붙여 캐릭터로 만들었습니다
- **파티 장식**: 위쪽 삼각 깃발, 떠다니는 네 갈래 별, 성공 때 터지는 반짝임과 색종이

### 체육과 융합을 "테마"가 아니라 "조작"에 넣었습니다
종목 이름만 체육으로 바꾸는 대신, 각 종목의 **핵심 판정 자체**가 체육 개념이 되도록 했습니다.

- **종목 1**: 골대가 소실점에서 다가오고 정답을 놓치면 지나가 버립니다. 정답을 통과하면 트랙이 빨라지며 "💨 질주!" — 속도 도전 그 자체입니다. 문제를 읽고 고를 시간이 있도록 접근 속도는 느긋하게 잡았습니다.
- **종목 2**: 정답이 손을 피해 **도망칩니다.** 목표 속도를 계속 새로 뽑아 그쪽으로 서서히 따라가게 해서, 쫓는 도중 속도가 랜덤하게 빨라졌다 느려졌다 합니다. 계속 쫓기면 숨이 차서(💨) 느려지므로 끈질기게 쫓으면 반드시 잡힙니다. 오답을 잘못 건드리면 실패 — 진짜 술래잡기의 구조입니다.
- **종목 3**: 원을 손으로 직접 그리는 조작은 저학년에게 너무 어려워서, **맞는 굴렁쇠에 손을 잠깐(0.7초) 대고 있으면** 손이 있던 자리부터 원이 저절로 그려져 나가도록 바꿨습니다. 중심에서 손까지의 거리가 반지름이라는 개념은 그대로 배우면서, 손 조작 자체는 훨씬 쉬워졌습니다.
- **종목 4**: 같은 분수라도 **원판 그림·띠 모형·숫자·말·대분수로 얼굴이 제각각**입니다. 겉모습이 달라도 같은 값임을 읽어내야 모을 수 있고, 조각마다 어떤 얼굴인지 작은 꼬리표로 알려 줍니다.
- **종목 5**: 상자가 하나씩 차례로 지나가면 기다렸다 고르기만 하면 되어 너무 쉬웠습니다. 지금은 **위·아래 두 줄이 서로 반대 방향으로 흐르며** 여러 상자가 동시에 나타나, 두 줄을 같이 살펴보고 정확히 골라야 합니다. 문제·상자 모두 "2 kg 300 g" 같은 복합 단위와 "2300 g" 같은 단일 단위가 뒤섞여 나와, 숫자만 보고 찍을 수 없고 실제로 단위를 변환해서 비교해야 합니다.
- **종목 6**: 선을 손가락으로 계속 따라 긋는 조작은 인식이 자주 끊겨 어려웠습니다. 지금은 **정답 줄의 발판을 순서대로 콕콕 짚기**로 바꿨습니다 — 손이 다음 발판 위를 지나가기만 하면 되고, 엉뚱한 곳을 스쳐도 실패하지 않습니다. 문제와 그림그래프도 화면 위쪽 한 판에 모아, 손을 움직이는 동안에도 계속 눈에 들어오게 했습니다.

### 아이가 억울하지 않도록
- 새 문제가 뜬 뒤 **0.55초 동안은 입력을 받지 않습니다.** 손이 우연히 정답/오답 위에 놓여 있었다고 문제를 읽어보기도 전에 처리되면 억울하기 때문입니다.
- 종목 2의 태그는 스치듯 여러 번 닿아도 게이지가 쌓이도록 천천히 식습니다.
- 종목 5는 상자 사이 간격을 판정 반경보다 넉넉히 벌리고, 범위 안에 여러 상자가 걸치면 **가장 가까운 것**을 고르도록 했습니다 — 손이 두 상자 사이에 있어도 엉뚱한 옆 상자가 먼저 판정되지 않습니다.

### 스스로 세고, 직접 겪어야 진짜 학습이 됩니다
- **종목 3**은 반지름·지름 숫자를 어디에도 텍스트로 알려주지 않습니다. 대신 모눈 위에 점선과 점만 찍어두고, 학생이 **직접 칸을 세어** 같은 크기의 굴렁쇠를 찾아야 합니다. 굴렁쇠 옆 표찰도 숫자 대신 색 점만 남겼고, 오답 피드백도 "몇 칸짜리였는지" 알려주지 않아 세지 않고 외워서 맞히는 길을 막았습니다. 모눈 선도 검정에 가깝게 진하게 그려 잘 보이도록 했습니다.
- **종목 6**은 숫자만 순서대로 누르던 밋밋한 방식에 재미를 더했습니다. 🐸 개구리가 발판 사이를 포물선을 그리며 폴짝 뛰어 건너고, 발판 밑은 잔물결이 이는 강물로 바뀌었습니다. 줄마다 하나씩 숨어있는 ⭐ 별 발판을 밟으면 보너스 점수가 붙고(모든 줄에 고르게 있어 정답을 알려주지 않습니다), 빠르게 연달아 밟으면 "🔥 N연속!" 스피드 스트릭이 뜹니다.

### 난이도를 더 세게
- **종목 2**의 도망 속도를 기존의 2배로 올렸습니다. 그만큼 숨이 찼을 때 더 크게 느려지도록 손봐서, 계속 쫓으면 여전히 반드시 잡히긴 하지만 훨씬 손에 땀을 쥐게 됩니다.
- **종목 5**의 문제 난이도를 전반적으로 올렸습니다. 3단계에서는 두 값 모두 kg와 g이 섞인 복합 단위 덧셈·뺄셈("2kg 300g + 1kg 800g" 같은)이 나올 수 있고, 숫자 범위도 넓혔습니다.
